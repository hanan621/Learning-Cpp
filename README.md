# 🪨📄✂️ Rock-Paper-Scissors Game in C++

## 🎮 About the Game
The Stone-Paper-Scissors game is an interactive game between the user and the computer. 
The user can choose the number of rounds they want to play, and the result and winner of each round are shown.
For more fun, colors and a sound effect have been added, along with a special way to display the final result of the game.

## ✨ Features
* 🎮 Choose the number of rounds (between 1 and 10) for each game.
* 🎲 Random selection for dynamic computer choices.
* 🎨 Changing colors on the console screen: yellow for draw, red for loss, and green for win.
* 📊 Final game summary and round results.
* 🔄 Replay option to start a new game.
